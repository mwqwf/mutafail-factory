# تذييل وصف أفلام قناة المتفائل

أمر المالك 2026-11-27: هوية القناة متخصصة في المعارك الإسلامية وبطولات أبطال المسلمين. يُختم وصف كل فيلم جديد بهذا التذييل، بعد المصادر والوسوم. لا تُستخدم عبارة «نبحث، ثمّ نروي» ولا «إن كانت هذه القصص تعنيك»، ولا وعد بفيلم مقبل.

```
«المتفائل» — معارك الإسلام وبطولات أبطاله.
إن كانت المعارك الإسلامية وبطولات أبطال المسلمين تعنيك فاشترك في القناة، وفعّل الجرس.
```
