> يُستبدل `{SLUG}` و`{N}` و`{MID}` و`{LAST}`. المستودع `mwqwf/{SLUG}-media` خاصّ، وفيه `shots.json` و`thumbs.json` و`AGENTS.md`.
> ⛔ لا تُرسل للمالك أكثر من هذه الثلاثة دفعةً واحدة، ولا رسائل تصحيح متفرّقة (رسالة مجمّعة واحدة عند الحاجة).

## القاعدة المشتركة (تُلصق في آخر كل أمر)
```
قواعد كل صورة:
- JPG جودة 85، دون 700 كيلوبايت، بالمقاس المحدّد، وتحقّق أن الملف يُفتح كاملاً قبل الـcommit:
  python -c "from PIL import Image; Image.open('<الملف>').convert('RGB')"
- بعد كل 5 صور: git pull --rebase origin main ثم commit ثم push إلى main (مهمّة أخرى تدفع بالتوازي).
- أسلوب موحّد: صورة وثائقية سينمائية واقعية photorealistic، إضاءة درامية طبيعية، ألوان دافئة ترابية.
- كل مسلم (محارب أو قائد أو عالم) من الخلف أو ظلاً بوجه غير ظاهر أبداً.
- دقّة العصر: لا مآذن ولا قباب مساجد قبل عصرها، ولا أسلحة أو عناصر حديثة، ودروع كل أمّة كما كانت في عصرها.
⛔ محرّمات مطلقة — افحص كل صورة وأعد ما خالف: لا نساء ولا فتيات ولا هيئة أنثوية · لا آلات موسيقية ولا عازفين · لا كتابة ولا حروف ولا أرقام ولا شعارات ولا علامات مائية داخل الصورة · لا أنبياء ولا صحابة بوجوه ظاهرة · لا أيقونات ولا فسيفساء ولا لوحات دينية فيها بشر أو ملائكة · لا صلبان على الرايات والتروس · لا نص قرآني · لا دماء مفرطة ولا أشلاء · لا عنصر غير مذكور في الوصف (فيلة، مبانٍ حديثة…).
⛔ لا تجعل المستودع عاماً، ولا تعدّل shots.json ولا thumbs.json ولا AGENTS.md. لا تتوقف لتسأل.
```
