1. توليد الصور بأداة الصور المدمجة عندما تكون متاحة للجلسة، ثم مراجعتها بصرياً: الملاءمة التاريخية، عدم النساء والآلات الموسيقية والكتابة، واتساق اللون والمكان والملابس.

3. إرفاق الصور المعتمدة داخل الحمولة المختومة مع `image_sources.json`. المستورد الجديد يعمل قبل المنزّل الأصلي؛ لكل صورة ناقصة/غير معتمدة/متغيرة يُستخدم الاحتياط.
4. حفظ الملفات الأصلية وبصماتها ومصدر كل صورة؛ لا إعادة توليد للمنجز عند استئناف الشوط.
5. لا تحويل تلقائي إلى API مدفوع. أداة هذه الجلسة لا تحتاج مفتاح OpenAI، لكنها ليست دليلاً على إتاحتها من GitHub Actions أو على سعة يومية مضمونة.

### عقد الإدخال

داخل الحمولة (لا تُدفع الصور الخاصة خاماً إلى المستودع العام):

```json
{
  "provider": "codex-imagegen",
  "primary": {
    "b01": {
      "file": "primary/b01.png",
      "approved": true,
      "sha256": "بصمة ملف الصورة",
      "prompt_sha256": "بصمة UTF-8 للوصف المطابق في images.json"
    }
  }
}
```

الحد الأدنى للقبول التقني 1024×576 بنسبة 16:9 (سماح صغير للتقريب)، وليس شهادة جودة. المستهدف صور ذات تفاصيل أصلية أعلى مع مساحة مناسبة لحركة العمق. لا توضع `approved: true` قبل النظر إلى الصورة.
يكتب المستورد `image_source_report.json` ويحتفظ بالأبعاد الأصلية حتى لا نسمي التكبير توليداً عالي الدقة.

## الصوت والجودة — ما تغيّر في هذه الدفعة

- لا تغيير للصوت المعتمد أو أصوات القناة ولا خلط نماذج في الفيلم.

- هذه البوابة تثبت اكتمال تقارير الفحص وحداثتها، **لا العصمة اللغوية ولا اجتياز البوابة البشرية أو صحة المصادر**.
