# مصنع المتفائل — محرّكٌ سحابيّ لإنتاج الوثائقيات

> **مستودعٌ عامّ عن قصد**: دقائقُ أكشنز بلا حدٍّ للمستودعات العامّة، والخاصّ ٢٠٠٠ دقيقة شهرياً
> والفيلمُ الواحد يستهلك نحو ٥٠٠ — أي أربعةُ أفلامٍ شهرياً لا فيلمٌ كلّ يوم.
>
> **ولا يُرى منه سرٌّ ولا نصّ:** كلُّ حمولةٍ تصل **مختومةً** بمفتاحٍ عامّ (`content_public.pem`)،
> ولا يفضّها إلا العدّاءُ بنصفها الخاصّ المخزَّن سرَّ أكشنز. والفيلمُ يُولد في العدّاء
> ويُرفع إلى يوتيوب ويموت معه — لا يُحفظ في مستودعٍ أبداً.

## الدورة
```
جلسةُ كلود (دماغ)  ──ختمٌ ودفعة──▶  ops/commands/<slug>/  ──زناد──▶  أكشنز (عضل)
      بحثٌ وسيناريو                  payload.enc + key.enc            صوت · صور · تصيير
                                                                      تركيب · رفعٌ ونشر
```
**والقاعدة الحاكمة:** الصلاحيةُ تبقى حيث هي، والأمرُ يُنقل إليها. فلا يُسلَّم الدماغُ سرّاً واحداً.

## أسرار الأكشنز
| السرّ | ما هو |
|---|---|
| `CONTENT_PRIVATE_KEY` | النصفُ الخاصّ لفضّ الحمولة |
| `GEMINI_KEYS_JSON` | مفاتيح التوليد الصوتي |
| `YT_OAUTH_JSON` | `{client_id, client_secret, refresh_token}` لقناة المتفائل |

## ما لا تبلغه الواجهة البرمجية — ويُسمّى بنصّه
- **ربطُ الريلز بالفيلم** (حقل «فيديو مشابه»): يُكتب الرابط في الوصف، ويُسجَّل المتبقّي في
  `ops/state/last_publish.json`؛ ويُربط بنقرةٍ من تطبيق يوتيوب (قناتك ← الشورت ← ⋮ ← تعديل ← فيديو مشابه).
- **العرضُ الأوّل (Premiere)**: الواجهة تجدول نشراً عامّاً بـ`publishAt`؛ وكونُه «عرضاً أوّل» لم يثبت بعد.
