# دليل مصنع المتفائل لصناعة الأثر

مهمتك ليست جعل كل جملة مثيرة، بل جعل المشاهد المناسب يفهم ويهتم ويثق ويخرج بمكافأة تستحق وقته. اكتب بالعربية الفصحى الحية، وقدّم الصدق والوضوح على أرقام النقر والمشاهدة. لا تعد بالانتشار ولا تزعم امتلاك «قوانين الدماغ».

## طريقة الاستخدام في Claude Code

هذا المجلد مهارة مستقلة بلا اعتماد على موصل أو نموذج صوت معين. عند وجوده داخل `.claude/skills/mutafail-storycraft/` يمكن استدعاؤه بالاسم في بيئة Claude Code الداعمة للمهارات؛ ويمكن أيضًا مطالبة Claude بقراءة هذا الملف ومراجعه مباشرة. لا تتطلب القراءة تشغيل سكربتات أو ربط حسابات. لا يعتبر هذا الملف إذنًا بالنشر أو الإنفاق أو استنساخ صوت أو رفع بيانات.

- للتصور أو كتابة السيناريو: اقرأ [الدراسة التحريرية](references/editorial-study.md).
- للصوت والصورة والمونتاج: اقرأ [دليل الإخراج](references/production-playbook.md).
- للتقييم والتطبيق: اقرأ [القوالب والاختبارات](references/templates-and-tests.md).
- لوزن الادعاءات ومراجعة الأصول: اقرأ [المصادر وحدود الدليل](references/evidence.md).

## أولوية تعليمات المصنع

قبل التطبيق اقرأ تعليمات المستودع الحالية، خصوصًا CLAUDE.md وAGENTS.md ودليل الاحتفاظ وسياسة المحتوى. هذه المهارة مكملة ولا تنسخ عقود الإنتاج. القيود الحالية تشمل منع الموسيقى وصور النساء وتصوير الأنبياء وإظهار وجوه الصحابة ومشاهد الأذى المحظورة، وتخصيص توليد الصور والبطاقات لكوديكس. التفاصيل في دليل الإخراج؛ عند التعارض لا تُسقط تعليمات المستخدم الأحدث لصالح قالب تشويق.

## مدخلات كافية لا استجواب طويل

استخرج من الطلب: موضوع الحلقة، الجمهور المحتمل، نوع الفيديو، المادة الموثقة، هدف المشاهد، المدة التقريبية، قيود الصور والصوت والحقوق. اقرأ أسلوب المشروع وتعليماته الحالية قبل الافتراض. إذا غابت بيانات الجمهور فاكتب «فرضية جمهور» ولا تخترع شخصية أو إحصاءات. لا توقف مسودة قابلة للمراجعة لسؤال شكلي؛ اسأل فقط عما يغيّر الدقة أو الحقوق أو نطاق العمل.

## سير العمل

1. **عقد المشاهدة:** جملة تحدد لمن هذا الفيديو، وما السؤال أو الخبرة التي يقدمها، وما الذي لا يعد به.
2. **ملف الحقيقة:** افصل الخبر الموثق، والخلاف، والتفسير، والتمثيل البصري. اربط الادعاءات بمصادرها. لا تستكمل فراغات التاريخ من الخيال.
3. **فرضيات الاهتمام:** حدد ما قد يهم الجمهور ولماذا، ودليل ذلك أو طريقة اختباره. لا تستنتج نفسيات الأفراد من هويتهم أو تعليق واحد.
4. **بدائل الزاوية:** قدّم زوايا مختلفة بالفعل، لا مرادفات لعنوان واحد. اختر على أساس القيمة وصدق الوعد وقابلية التنفيذ.
5. **هندسة الحلقة:** ابنِ الوحدات السببية والانتقالات. لكل فقرة وظيفة، وسؤال أو حاجة فهم، ومعلومة تغيّر الفهم، ومكافأة. ليس لازمًا تعليق كل نهاية أو إخفاء كل إجابة.
6. **السيناريو المسموع:** اكتب كلام الراوي مستقلًا عن تعليمات الأداء؛ جرّب منطوقًا عينة قصيرة قبل تثبيت المدة. لا تقدّر العربية من سرعة إنجليزية ثابتة.
7. **الإخراج الدلالي:** اربط كل لقطة وصمت ومؤثر بوظيفة؛ اختر الصوت حسب المقام، لا حسب الرغبة في الصراخ. ضع وسمًا صريحًا للتمثيل أو التوليد حين يلزم.
8. **المراجعة المضادة:** ابحث عن وعد لا يُوفى، وتكرار، واختلاق دوافع، وغموض أسماء، ولقطة مضللة، وأداء مبالغ فيه. صحح قبل تجميل النص.
9. **خطة تعلم:** سجّل الفرضية، والنسخة، والمقياس المناسب، والمخاطر، وما الذي سيغير قرارنا. لا تنتج بيانات احتفاظ أو درجات نجاح من الخيال.

## المخرج الافتراضي

سلّم حزمة مناسبة لحجم الطلب، دون حشو:
- موجز الجمهور والوعد وحدود التوثيق.
- بدائل الافتتاحية مع سبب الترشيح، لا «توقع نسبة انتشار».
- خريطة الفقرات ثم نص الراوي.
- جدول إنتاج يربط المعنى والصوت والصورة والمصدر.
- العنوان والمصغرة بوصفهما وعدًا واحدًا، ثم خطة تحقق وتعلم.

إذا طُلب نقد نص موجود، ابدأ بأكبر ثلاثة عوائق وأمثلة إصلاح فعلية، لا إعادة كتابة كاملة بلا حاجة. إذا طُلب ريلز من فيلم، أعد بناء وحدة مستقلة مفهومة؛ لا تقص مقطعًا زمنيًا عشوائيًا.

## حواجز الجودة

- لا اقتباسات أو أرقام أو حوارات أو نوايا تاريخية مختلقة. استخدم placeholders واضحة للمعلومة الناقصة ولا ترسلها للإنتاج كأنها حقيقة.
- لا تجعل الجذب ذريعة للتهويل الديني أو التحريض أو ازدراء الجمهور أو الاستغلال العاطفي.
- لا تسوّق مقياسًا تحريريًا بوصفه اختبارًا نفسيًا أو تنبؤًا خوارزميًا.
- لا تقترح آلية TTS أو SSML دون التحقق من دعم المزود/النموذج؛ ولا تضع تعليمات الأداء في النص الذي سيُنطق.
- لا تنسب مشاعر محددة إلى الجمهور بلا دليل، ولا تعتبر إعادة المشاهدة إعجابًا بالضرورة.
- لا تنشئ وسائط أو تربط MCP أو تثبّت حزمًا ضمن مجرد طلب كتابة أو مراجعة.
- لا تغيّر ملف تعليمات المشروع ولا تفرض هذه المهارة على أعمال أخرى.
