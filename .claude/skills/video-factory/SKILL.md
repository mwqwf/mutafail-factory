# مدخل مصنع المتفائل في Codex

المسارات الآتية نسبية إلى جذر المستودع، لا إلى جهاز المالك. اقرأ `AGENTS.md` ثم
`skill/SKILL.md` و`skill/PLAN.md` كاملين. مراجع المراحل في `skill/references/`؛
اقرأ مرجع المرحلة قبل تنفيذها وفق جدول المهارة الأصلية.

## طبقة التوافق السحابي

- الحالة الحاكمة هي `ops/state/plan_state.json` لا النسخة التاريخية `skill/PLAN_STATE.json`.
- قبل الاستئناف اقرأ `ops/ENGINE.md` و`ops/CAPABILITIES.md` و`ops/CODEX_PRODUCTION_PLAN.md`؛ تميّز الأدلة من الخطط. لا تعِد إنتاج حلقة مكتملة أو رفعها لأن شوط متابعة فشل.
- تعليمات Desktop وDownloads و`~/.claude` في الأصل تاريخية. استخدم أدوات `tools/` وملفات المستودع ومسارات التنفيذ السحابي الموثقة. لا تجعل جهاز المالك أو هاتفه شرط استمرار.
- الأسرار تبقى في مخزن GitHub: `CONTENT_PRIVATE_KEY` و`GEMINI_KEYS_JSON` و`YT_OAUTH_JSON`. لا تبحث عن قيمها في المستودع العام ولا تنسخها في مهارة أو سجل أو أمر مكشوف. صلاحية قراءة المستودع لا تعني صلاحية أسرار Actions.
- إذا لم يكن gh موثقاً أو لم يوجد origin، افحص أدوات GitHub المتصلة في الجلسة قبل الحكم بانعدام الوصول: قد تتيح قراءة الملفات والسجلات وكتابة التغييرات وطلبات الدمج بصورة مستقلة عن CLI. جرّب القراءة أولاً؛ وجود اسم الأداة لا يثبت صلاحيتها، ولا تُعدّل ملفاً لمجرد اختبار الاتصال.
- أداة توليد الصور هنا قدرة تُفحص من قائمة الأدوات، لا افتراض. إن غابت، لا تدّع أنها متاحة أو أنها تكفي عدد الصور اليومي. احتفظ بـ`imgdl3.py` الأصلي، واستخدم الصور المعتمدة عبر `tools/image_sources.py` حين تتوفر، دون حذف الاحتياط.
- لا تعتمد أرقام الحصص التاريخية وعداً حاضراً، ولا تولّد مادة لأجل اختبار الرصيد. القياس من سجلات الإنتاج والحصة الفعلية؛ لا تدوير حسابات أو إنشاء مشاريع للتحايل على حدود المزوّد.
- لا تعتبر تكليف الإنتاج إذناً مالياً لـGitHub Actions. قبل تشغيل أو إعادة تشغيل أو جدولة أي workflow
  افحص خصوصية المستودع ونوع العدّاد وتخزين Artifacts/Cache. `ubuntu-latest` لا يكفي وحده؛ العام مع
  العدّاد القياسي مجاني للدقائق وفق توثيق GitHub، لكن التخزين قد يُحاسب. عند تعذر إثبات المجانية
  أبقِ التشغيل موقوفاً قابلاً للعكس، واستعمل بيئة الجلسة، ولا تُعد بناءً أو اختباراً على الرأس نفسه.
- يجب أن تجتاز المادة التفنيد والبوابات اللغوية والسمعية والبصرية قبل النشر. الحالة المجهولة في الاستماع ليست ناجحة؛ والتحكيم على بصمة المحتوى الحالي.
- المخرجات الوسيطة في المستودع العام مشفّرة عبر `.github/actions/private-upload` و`private-download`. لا تُرفع حمولة أو وسائط غير منشورة خاماً. التشفير لا يجعل مدة احتفاظ يومين كافيةً لأسابيع، ولا يحمي آثاراً قديمة بأثر رجعي.
- `pulse.yml` لا يوقظ نموذجاً للبحث والكتابة؛ يطلق مسار الاستئناف المحدد في شفرته. لا تصف نبضة أو جلسة منفردة بأنها مشرف يعمل دائماً.

## فحص آمن بلا توليد

من جذر المستودع:

```sh
python -m unittest discover -s tools -p 'test_*.py'
node tools/test_listen_cache.js
node --check tools/listen.js
node --test tools/test_artifact_crypto.mjs
```

سجّل النقطة التالية والأثر المتحقق وحدود الاختبار في ملفات الحالة. هذه المهارة
تنقل تعليمات التشغيل، وليست تفويضاً يتجاوز طلب المالك أو متطلبات المنصة.
