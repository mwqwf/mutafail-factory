# هوية المتفائل المعتمدة — 25 سبتمبر 2026

اعتمد المالك الهوية الذهبية والفيروزية والكحلية، وطلب توحيد الأيقونة مع الغلاف وإبراز الرمز. الشعار: كتاب مفتوح وشمس صاعدة وطريق نحو المعرفة. العبارة: «نبحث، ثمّ نروي».

- `../logo.png`: الأيقونة المعتمدة، 800×800، أصل المصنع للأفلام والشورتات والمصغرات.
- `banner.jpg`: غلاف القناة 2560×1440؛ فُحص قص الهاتف المركزي 1546×423 ويظهر الاسم والرمز والعبارة كاملة.
- `watermark.png`: نسخة 400×400 لعلامة يوتيوب المائية، أقل من ميغابايت.
- `manifest.json`: بصمات الأصول؛ يمنع `fetch_logo.py` الكتابة فوق الهوية المعتمدة بصورة حساب قديمة.

التصميم عبر أداة `image_gen` المدمجة، ثم تصدير المقاسات والضغط فقط عبر FFmpeg. مواصفة الأيقونة: نفس رمز وخط الغلاف المعتمد، رمز أكبر واضح، ذهبي وفيروزي، خلفية كحلية، مركز آمن للقص الدائري. مواصفة الغلاف: الحفاظ على الهوية، نسبة 16:9، جميع النصوص والرمز داخل الشريط الآمن في الوسط، زخارف العلوم والحضارة خافتة عند الأطراف.

تأخذ `mont3d.py` و`mkreel3d.py` و`mkthumb.py` الأصل نفسه من `envpaths.logo()`؛ يسبق أصل المستودع نسخ الجهاز القديمة. لا تعديل لأي ملف فيديو منشور سابقاً.

تطبيق الغلاف والعلامة المائية: سير العمل اليدوي `channel-branding.yml` على `master`، باستعمال `YT_OAUTH_JSON` الموجود، مع تحقق معرّف القناة وحفظ بياناتها الأخرى وقراءة الغلاف بعد تحديثه. ليس له تشغيل عند الدفع، ولا تخزين artifacts أو cache، ولا توليد صوت أو صور. لا تُعد تشغيله تلقائياً عند مهلة غامضة قبل قراءة أثر التطبيق.

صورة حساب القناة لا تدعم واجهة Data API تغييرها؛ تُرفع `../logo.png` من تخصيص القناة في الاستوديو. قبول `watermarks.set` يثبت قبول الطلب فقط؛ مشاهدة العلامة في المشغّل فحص مستقل.

تحقق دون شبكة: `node tools/channel_branding.mjs --verify-local` و`node --test tools/test_channel_branding.mjs`، وحارس `python tools/logocheck.py`. تُسجل نتيجة الاختبار الفعلي والتطبيق في `ops/BRANDING_2026-09-25.md`.
